## 📅 Your one-month plan

ദിവസം 30 മിനിറ്റ്, നാലു ആഴ്ച. (30 minutes a day, four weeks.)

| Week | Do this |
|---|---|
| 1 | Finish one course from **Everyone**. Use AI every day for one real task at work or study. |
| 2 | Start the first course for **your field** above. Write down 3 tasks you repeat every week. |
| 3 | Do those 3 tasks with AI. Check every answer; note what it got wrong and how you fixed it. |
| 4 | Finish the field course. Turn one result into proof: "this report took 3 hours, now 20 minutes", or a GitHub project. Put it on your resume and LinkedIn. |

Then repeat with the next course. The people who can give AI work and check it are the ones who get through this change.

### Install in the Claude app (claude.ai, desktop or phone)

1. Download the ZIP for the skill (don't unzip it).
2. In Claude, open **Settings → Capabilities** and turn on **Code execution and file creation** (skills need it).
3. Open **Customize → Skills**, tap **+**, then **Create skill → Upload a skill**, and choose the ZIP.
4. Start a new chat and say, for example: *"I work in a bank. Help me get ready for AI."*

Skills work on the Free, Pro and Max plans as long as code execution is on. Menu names may differ slightly; see
Anthropic's guide: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

### Install in Claude Code (the AI agent in your terminal)

Claude Code can also save your plan to a file (`ai-career-plan.md`) and remember your progress across sessions.
Install all seven in one go (macOS / Linux / WSL):

```bash
for s in ai-career-coach office-ai-assistant business-ai-marketer teacher-ai-helper health-ai-helper trades-ai-helper tech-career-lab; do
  mkdir -p ~/.claude/skills/$s && curl -fsSL https://raw.githubusercontent.com/aitechvartha-techie/ai-tech-vartha/main/job/skills/$s/SKILL.md -o ~/.claude/skills/$s/SKILL.md
done
```

Then start a new Claude Code session and say *"use ai-career-coach"*.

### A note on privacy

Don't paste customer, patient or student details (names, account numbers, Aadhaar, phone numbers) into any AI
tool your workplace hasn't approved. The skills remind you, but it's your call.
